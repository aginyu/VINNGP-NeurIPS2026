# VINNGP-NeurIPS2026
Codes for the NeurIPS 2026 paper Efficient Variational Inference for Log-Gaussian Cox Processes via Voronoi Tessellation.
If time permits, we hope to refine the core algorithm (e.g. updating kernel parameters, trying other type of optimization methods and writing Rcpp codes) and build a package. We welcome anyone interested in this project to make suggestions.

Below, we first provide an overview of all R code files included in the directory, followed by a description of the experimental workflow. Before the experiments, you should set the current directory at the same level of this README file, and create a new folder named as `data`.

## Synthetic Data Generation
- `./src/data_pattern_generator.R`: Simulates point patterns generated by an LGCP model.
- `1_lgcp_full_case.R`: Generate observation points, covariates, and the integration points and weights required for approximating the LGCP likelihood.

## NNGP construction and Model Fitting
- `./src/dual_mesh_loc.R`: Performs Voronoi tessellation over the observation domain to obtain integration points and weights used in approximating the LGCP likelihood.
- `./src/NNMatrix.R` and `./src/functions.R`: Contain functions for efficiently computing the NNGP approximation of the prior covariance matrix. These files are adapted from https://github.com/LuZhangstat/ConjugateNNGP 。
- `2_nngp_prior.R`: Compute the NNGP prior approximation.
- `optimization_hyper_diag.R`: The core implementation of the VoGCAM algorithm.
- `3_full_case_result.R`: Provide comparison results between the proposed method and baseline methods such as INLA and VIFRK.

## Visualization of Experimental Results
- `./src/logintensity_vis.R`: Visualizes the posterior mean surface and posterior standard error surface of the LGCP log-intensity.
- `4_plot_result_single.R`: Plots and compares the LGCP log-intensity posterior mean surface and posterior standard error surface

# Experimental Workflow
Run the following scripts in order:
- `1_lgcp_full_case.R` -> `2_nngp_prior.R` -> `3_full_case_result.R` -> `4_plot_result.R`.
- Compiling the Stan code in `2_nngp_prior.R` may take about 30-40 seconds. If the compilation failed, one could try restarting R and run the same file again.
